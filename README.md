## 🚀 Deployment Instructions

### 1. Standalone / GitHub Pages Preview
Simply open `index.html` in any modern web browser or enable **GitHub Pages** from repository settings (deploy from `master` branch root).

### 2. Shopify Store Upload
1. Log into your **Shopify Admin**.
2. Navigate to **Online Store > Themes**.
3. Under **Theme library**, click **Add theme > Upload zip file**.
4. Upload `Meenu_Label_Shopify_Theme.zip`.
5. Under **Products**, click **Import** and upload `Meenu_Label_Shopify_Products_Import.csv` to publish all 16 debut silhouettes instantly.
